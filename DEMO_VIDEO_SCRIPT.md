## Recording Notes

### Tools Needed:
- Screen recording: OBS Studio or Loom
- Video editing: DaVinci Resolve (free) or iMovie
- Voiceover: Clear microphone
- Background music: Subtle, upbeat (royalty-free from Epidemic Sound)

### Recording Tips:
1. **Prepare environment:**
   - Clean browser (no bookmarks visible)
   - Test agent works perfectly
   - Have all URLs ready
   
2. **Screen resolution:** 1920x1080

3. **Recording order:**
   - Record all screen actions first
   - Add voiceover after
   - Sync in editing

4. **B-Roll:**
   - Record extra shots for transitions
   - Multiple takes of key moments
   - Have backup demos ready

### Editing Checklist:
- [ ] Add intro animation (OpenPaw logo)
- [ ] Add on-screen text callouts
- [ ] Add subtle background music
- [ ] Color grade for consistency
- [ ] Add transitions between scenes
- [ ] Add captions (for silent viewing)
- [ ] Export 1080p MP4
- [ ] Test on mobile devices
