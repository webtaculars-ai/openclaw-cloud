## 🎤 Recording Tips

### Audio Quality:
- Record in quiet room (no background noise)
- Use headset mic or external mic (avoid laptop built-in)
- Speak clearly and at moderate pace
- Practice script 1-2 times before recording
- Don't worry about perfection - authentic is better

### Video Quality:
- Record at 1080p if possible (minimum 720p)
- Use screen recording at 100% browser zoom
- Hide OS notifications before recording
- Close unnecessary tabs/apps
- Use cursor smoothly (don't jerk mouse)

### Pacing:
- Speak conversationally (not rushed)
- Pause briefly between sections
- Match voiceover to what's on screen
- If you mess up, pause and restart that section (edit later)

## 🛠️ Recording Tools

### Recommended: Loom (Easiest)
1. Install Loom browser extension or desktop app
2. Click "Record" → "Screen + Webcam" or "Screen Only"
3. Select browser window or full screen
4. Hit record and follow script
5. Loom auto-uploads and gives you a shareable link
**Pros:** Super easy, instant sharing, free tier available  
**Cons:** 5-minute limit on free tier (you're at 3 min so OK)

### Alternative: OBS Studio (Free, Professional)
1. Download OBS Studio (free)
2. Add "Display Capture" or "Window Capture" source
3. Add "Audio Input Capture" (your mic)
4. Hit "Start Recording"
5. Follow script
6. "Stop Recording" → File saved locally
7. Upload to YouTube, Vimeo, or Google Drive
**Pros:** No time limits, professional quality, free  
**Cons:** Slight learning curve (but worth it)

### Quick & Easy: QuickTime (Mac) or Windows Game Bar
**Mac:**
1. Open QuickTime Player
2. File → New Screen Recording
3. Click record, select area or full screen
4. Follow script
5. Stop recording → Save file
6. Upload to YouTube/Drive

**Windows:**
1. Press Windows + G (opens Game Bar)
2. Click "Capture" → "Record"
3. Follow script
4. Stop recording
5. Find video in Videos/Captures folder
6. Upload
