## 4. Product Details

### What We Sell

**Product:** OpenPaw - Managed AI Agent Infrastructure

**Description:**
OpenPaw provides hosted, privacy-first AI agents powered by OpenClaw. Users get personal AI assistants that can:
- Browse the web and automate tasks
- Schedule automated actions (cron jobs)
- Communicate across multiple platforms (Telegram, WhatsApp, Discord)
- Use cutting-edge AI models (Claude Sonnet 4.5 via AWS Bedrock)

### How It Works

**Technology Stack:**
- Built on OpenClaw (open-source framework)
- Hosted on AWS infrastructure (ECS, DynamoDB, Lambda)
- Uses AWS Bedrock for AI models (Claude, licensed through Amazon)
- Each user gets isolated containerized agent

**Licensing:**
- OpenClaw: Apache 2.0 License (open source)
- AI Models: Licensed through AWS Bedrock (we're authorized reseller)
- Our Platform: Proprietary hosting & management layer

### Target Customers

**Primary Audience:**
- Tech-savvy professionals (developers, founders, managers)
- Privacy-conscious users who want self-hosted AI benefits without complexity
- Business users needing AI automation

**Use Cases:**
- Personal assistants (schedule management, reminders)
- Research & analysis (web scraping, data gathering)
- Business automation (form filling, data entry)
- Multi-platform communication (one AI, all channels)

### Purchase Model

**Single Purchases (Credits):**
- No subscriptions
- Users buy credit packages as needed
- Credits used for actual AI API calls
- Transparent usage tracking

**Why Not Subscriptions:**
- Fair pricing (pay only for what you use)
- No vendor lock-in
- Credits never expire
- Aligns with our privacy-first values

### Fulfillment

**Digital Service:**
- Instant provisioning (30-60 seconds after payment)
- User receives agent credentials immediately

**No Physical Products:**
