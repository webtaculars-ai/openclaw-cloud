## Taking Screenshots NOW

### Tools:
- Browser: Chrome/Firefox DevTools (responsive mode)
- Screenshot: Native OS (Cmd+Shift+4 on Mac, Snipping Tool on Windows)
- Editing: Preview/Paint (crop to consistent size)

### Process:
1. Open each URL
2. Set browser to 1920x1080 viewport
3. Take clean screenshot (no browser chrome)
4. Crop to focus area
5. Save as PNG
6. Name: 01-hero.png, 02-pricing.png, etc.

- [ ] Text is crisp and readable
